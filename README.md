# Palak Choudhary — Portfolio

Personal portfolio website for **Palak Choudhary**, a Full Stack MERN Developer.

A single, self-contained `index.html` — no build step, no dependencies. Just open it in a browser.

## Run locally

```bash
npx -y serve .
```

Then open the URL it prints (e.g. `http://localhost:3000`). Or simply double-click `index.html`.

## Tech

Plain HTML, CSS, and vanilla JavaScript. Fonts from Google Fonts (Space Grotesk, Inter, JetBrains Mono).

## Deploy

Hosted as a static site — works on GitHub Pages, Vercel, or Netlify with zero configuration.
